<h1 align="center">
  Shreyas Sharma Portfolio
</h1>
<p align="center">
  A Vite + React portfolio for software engineering, Webex Contact Center widgets,
  developer tooling, webinars, and Unreal Engine 5 side projects.
</p>

## 🛠 set-up

1. Install the dependencies

   ```sh
   npm install
   ```

2. Start the development server

   ```sh
   npm run dev
   ```

## 🚀 build and run for production

1. Generate a full static production build

   ```sh
   npm run build
   ```
